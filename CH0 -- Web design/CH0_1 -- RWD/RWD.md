# RWD (Responsive Web Design)
## intro
It is a design pattern that simply create a web app for different web browser. 

In this design pattern, one don't to manually adjust the component through setting different size with `@media` annotation.

## principle
In RWD pattern, it must satisfy these rules.

+ **NEVER** exists horizontal scroll bar, unless uncessary.

+ **Don't** have to manually adjust the component through setting different size with `@media   ` annotation.
